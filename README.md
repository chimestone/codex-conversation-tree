# 对话枝图

在 Codex 的独立浏览器面板里查看项目对话的真实分支，并用独立文件夹整理对话。仅本机运行，无需安装第三方依赖。

## 启动

需要 Node.js 24 或更新版本。已在 Windows + Node.js 24.13.1 上验证。

Windows 用户可以双击 `start-panel.cmd`，使用期间保持启动窗口打开。也可以使用下面的命令启动。

在本目录打开终端：

```powershell
node server.mjs
```

打开 http://127.0.0.1:43127 。也可以让 Codex“在右侧打开对话枝图 http://127.0.0.1:43127”。服务监听本机回环地址，不接受局域网访问。在启动终端按 Ctrl+C 停止；停止后面板无法刷新或保存。

默认选中工具所在目录匹配的 Codex 项目；无法匹配时选中“未归属”。可在顶部切换其他本地项目。本工具不安装后台服务或开机自启动。

## 使用

- **真实分支**：图形树从左向右生长，项目位于左侧，子对话位于父对话右侧。虚线表示项目归属，实线表示真实父子关系。可逐级折叠、展开或全部展开；使用 ＋ / − 在 10%–500% 范围内自由缩放（超出画布后不会自动缩回）、“适应画布”查看全图，放大后可横向及纵向滚动。标题搜索保留匹配节点的祖先路径，并临时展开搜索结果。
- **选择菜单**：项目、上级文件夹和移入文件夹使用统一的绿色菜单，支持输入名称筛选、方向键选择和 Escape 关闭。
- **我的分组**：新建文件夹，选择文件夹编辑名称及上级；选择对话后使用“移入文件夹”。删除文件夹会将直接内容移到上级，绝不删除对话。
- **详情**：显示更新时间、工作目录、分叉来源和 ID，可复制 ID。首版不提供未经验证的跳转原对话按钮。
- **归档与刷新**：默认不显示归档对话；可勾选显示。点击“刷新数据”读取最新元数据。读取时间和完整时间使用北京时间，数据不是实时运行状态。
- **来源提示**：缺失父对话、跨项目来源、隐藏的归档父对话或异常循环均会标记。来源无法读取的节点不应被当作已确认的独立根。

## 数据与兼容性

- 默认只读 `%USERPROFILE%\.codex`，可通过 `CODEX_HOME` 指定其他本地数据目录。
- 只读最新编号的 `state_*.sqlite` 元数据列、`.codex-global-state.json` 的项目映射，以及 `sessions` / `archived_sessions` 中会话首行。支持 `.jsonl` 与 `.jsonl.zst`，压缩文件流式解压到首行即停止，不解析聊天正文。
- 合并旧版、新版项目编号；优先明确归属，之后按工作目录最长前缀匹配。内部审核、子代理不会混入用户对话。云端 ChatGPT 不在本工具范围内。
- 人工整理仅保存在 `data/organization.json`，第一次保存分组时创建。备份此文件即可保留整理结果；缺失对话的旧分组引用会保留，以便对话恢复后继续使用。
- 分组原子保存并检查版本；多面板冲突会要求刷新，避免静默覆盖。
- 所有内容均留在本机，页面不使用外部字体、脚本、统计或上传服务。

## 接口与代码结构

- `GET /api/snapshot`：缓存的项目与对话元数据。添加 `?refresh=1` 重新读取。
- `GET /api/organization`：人工分组及版本号。
- `PUT /api/organization`：保存完整分组，必须携带当前 `revision`；冲突返回 409。
- `lib/codex-reader.mjs`：私有数据格式适配；`dist/tree.mjs`：树、搜索、分组模型。
- `dist/`：页面与交互；`server.mjs`：本地 HTTP 服务。

这些接口不提供聊天正文、任意文件读取、消息发送或原始对话修改能力。服务校验 Host / Origin，不开放跨域。

## 故障处理

- **端口被占用**：先检查是否已启动。需要另一个端口时执行 `$env:PORT='43128'` 再启动，并打开对应 URL。
- **SQLite experimental 提示**：Node.js 24 内置 SQLite 的提示，不代表读取失败。
- **数据格式不兼容**：Codex 更新可能改变私有格式；页面会显示错误。请更新读取适配器，不要删除或重建 Codex 数据库。
- **分叉来源读取失败**：面板保留对话并标记不确定来源；文件可能缺失或格式变化，不通过标题猜测关系。
- **人工分组损坏**：应用保留原文件并禁用分组编辑；从备份恢复 `data/organization.json` 后刷新。真实分支仍可读取。
- **分组保存冲突**：另一个面板先保存了更新，点击刷新后再编辑。
- **复制失败**：手动选中详情里的 ID 复制。

## 验证

```powershell
node --test
```

测试使用临时目录和人工会话数据，不修改真实 Codex 数据。覆盖真实树、归档、循环、搜索祖先、中文路径、压缩元数据、人工分组持久化、版本冲突、损坏文件保留，以及接口边界。

测试涵盖横向布局与节点不重叠等关键行为。个人验收记录、真实会话截图和分组数据均排除在 Git 提交之外。

## 项目定位

这是非官方的 Codex 本地辅助工具，不修改 Codex 原生侧栏。当前为 Windows 首版，依赖 Codex 的本地内部存储格式；不能承诺与所有客户端版本兼容。上传代码到 GitHub 不等于把面板部署上线：面板仍需要在拥有本地 Codex 数据的电脑上运行。
